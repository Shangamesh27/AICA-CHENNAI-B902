How to add an app and prompt

Upload matching files to the apps folder in GitHub, for example My App.html and My App.txt. You can also put one HTML app and a Prompt.txt file together in a separate project folder. Names appear automatically after both files are uploaded. Markdown (.md) prompts are also supported.

Keep existing project files when adding new ones, then select Refresh projects. New apps may take a few minutes to become available after upload.
